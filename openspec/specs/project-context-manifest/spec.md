# project-context-manifest Specification

## Purpose
Определяет переносимый и безопасный манифест проекта, по которому OpenSpec Studio восстанавливает название и набор read-only Git-репозиториев контекста.
## Requirements
### Requirement: Формат манифеста контекста
Система SHALL читать только корневой файл `.openspec/context.yaml`, содержащий непустое строковое поле `name` и массив строковых Git URL в `context.repositories`.

#### Scenario: Корректный манифест
- **WHEN** клонированный Store содержит корректные `name` и `context.repositories`
- **THEN** система возвращает нормализованное имя и список репозиториев для импорта

#### Scenario: Манифест отсутствует
- **WHEN** `.openspec/context.yaml` отсутствует
- **THEN** система сохраняет совместимый ручной сценарий и не пытается автоматически импортировать репозитории

### Requirement: Строгая валидация манифеста
Система MUST отклонять манифест с неизвестными полями, пустым именем, неверными типами, credential-bearing URL или URL неподдерживаемой схемы до запуска контекстного Git clone.

#### Scenario: Ошибка структуры YAML
- **WHEN** поле `context.repositories` не является массивом строк или манифест содержит неизвестное поле
- **THEN** создание проекта завершается безопасной ошибкой `INVALID_CONTEXT_MANIFEST` без запуска контекстных clone-операций

#### Scenario: Недопустимый Git URL
- **WHEN** хотя бы один элемент `context.repositories` не проходит действующую проверку Git URL
- **THEN** система возвращает `INVALID_CONTEXT_REPOSITORY_URL` и не запускает ни один контекстный clone

### Requirement: Нормализация списка контекста
Система SHALL удалять точные дубликаты нормализованных Git URL с сохранением порядка первого появления.

#### Scenario: Повторяющийся URL
- **WHEN** один URL несколько раз указан в `context.repositories`
- **THEN** репозиторий клонируется и регистрируется только один раз

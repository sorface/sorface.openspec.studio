## Purpose

Предварительный просмотр и контролируемое принятие AI-изменений целиком, по файлам или отдельным hunks в новые ревизии черновиков.

## Requirements

### Requirement: Нормализованный diff
Система SHALL показывать предложенный AI diff относительно исходной версии до любого применения результата.

#### Scenario: Несколько файлов
- **WHEN** AI предлагает изменения нескольких OpenSpec-файлов
- **THEN** UI показывает список файлов и unified или side-by-side diff каждого файла

### Requirement: Уровни принятия
Система SHALL позволять принять или отклонить весь diff, выбранные файлы либо отдельные hunks.

#### Scenario: Частичное принятие
- **WHEN** пользователь выбирает один hunk из нескольких
- **THEN** только выбранный hunk попадает в новую ревизию соответствующего черновика

### Requirement: Черновик как результат
Система MUST сохранять принятые AI-изменения только как внутренний черновик и MUST NOT автоматически записывать их в working tree.

#### Scenario: Принят весь diff
- **WHEN** пользователь подтверждает результат AI
- **THEN** создаются ревизии черновиков, а Git status не меняется

### Requirement: Атомарность частичного patch
Система SHALL проверять совместимость выбранных hunks и не изменять черновик частично при ошибке применения.

#### Scenario: Конфликт hunks
- **WHEN** выбранные hunks нельзя согласованно применить к базовой версии
- **THEN** система возвращает `HUNK_CONFLICT`, сохраняя прежний черновик без изменений

### Requirement: Отклонение результата
Система SHALL позволять полностью отклонить предложение без изменения черновиков и working tree.

#### Scenario: Пользователь отклонил diff
- **WHEN** пользователь выбирает действие отклонения
- **THEN** операция получает статус rejected, а предложенные изменения больше не доступны для записи

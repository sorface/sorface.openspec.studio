## MODIFIED Requirements

### Requirement: Контекст workspace
Система SHALL получать доступный контекст workspace из локального API и показывать в верхней панели активный проект, Store path или worktree, AI-провайдера, модель и состояние локального сервера без подмены серверных данных демонстрационными значениями.

#### Scenario: Контекст загружен
- **WHEN** локальный API возвращает активный проект и системные capabilities
- **THEN** UI показывает возвращённые название проекта, Store path, провайдера, модель и доступность инструментов

#### Scenario: Инструмент недоступен
- **WHEN** выбранный CLI не обнаружен
- **THEN** UI показывает недоступность и действие перехода к настройке пути

### Requirement: Обязательные состояния
Каждый экран SHALL иметь различимые состояния loading, empty, success, error, cancelled, unavailable tool, backend unavailable, draft conflict и long-running progress, когда они применимы, и MUST NOT представлять имитированную операцию как успешный серверный результат.

#### Scenario: Загрузка проектов
- **WHEN** UI ожидает ответ списка проектов
- **THEN** переключатель проекта показывает loading и не предлагает операции над ещё не загруженными данными

#### Scenario: Нет проектов
- **WHEN** локальный API возвращает пустой список проектов
- **THEN** UI показывает empty state и доступное действие создания проекта

#### Scenario: Backend недоступен
- **WHEN** запрос системных данных или проектов завершается сетевой ошибкой
- **THEN** UI показывает backend unavailable, сохраняет несохранённый ввод текущей browser-сессии и предлагает повторить запрос

#### Scenario: Длительная операция
- **WHEN** сервер возвращает `operationId`
- **THEN** UI показывает прогресс или поток событий и доступное действие отмены

### Requirement: Понятное исправление ошибок
Система SHALL показывать пользователю безопасное объяснение ошибки, конкретное допустимое действие для восстановления и correlation ID, когда он возвращён локальным API.

#### Scenario: Ошибка Project API
- **WHEN** операция с проектом отклонена локальным API
- **THEN** UI показывает безопасное серверное сообщение, доступное повторное действие и correlation ID без технического stack trace

#### Scenario: Git auth failed
- **WHEN** push завершается `GIT_AUTH_FAILED`
- **THEN** UI предлагает проверить системный credential helper без отображения credentials

## ADDED Requirements

### Requirement: Автоматический импорт репозиториев из Store
Система SHALL последовательно клонировать каждый уникальный Git URL из корректного `.openspec/context.yaml` в управляемую область созданного проекта и регистрировать успешный clone как `readOnlyForAi: true`.

#### Scenario: Автоматическая загрузка полного контекста
- **WHEN** Store содержит доступные репозитории в `context.repositories`
- **THEN** после завершения создания проекта все они отображаются на странице «Контекст» и доступны AI только для чтения

#### Scenario: Ошибка одного репозитория
- **WHEN** один remote не клонируется, а остальные доступны
- **THEN** система продолжает импорт следующих URL, сохраняет успешные подключения и сообщает безопасную ошибку неуспешного URL

### Requirement: Безопасность автоматического clone
Система MUST применять к автоматическому импорту те же ограничения URL, управляемого пути, Git environment, SSH agent и проверки worktree, что и к ручному подключению репозитория.

#### Scenario: URL пытается стать CLI-аргументом
- **WHEN** значение URL начинается с `-` или содержит управляющие символы
- **THEN** система отклоняет весь манифест до запуска Git

#### Scenario: Клонированный каталог не является отдельным worktree
- **WHEN** Git clone завершился, но канонический корень не совпадает с управляемым target
- **THEN** репозиторий не регистрируется и в сводке возвращается безопасная ошибка проверки
